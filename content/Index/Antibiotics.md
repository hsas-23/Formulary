## 🧠 メモ

- 広域抗菌薬は可能な限りデエスカレーション  
- PK/PD（特にβラクタムはTime above MIC）を意識  
- 腎機能に応じた投与調整は必須

## ファイル一覧

```dataview

TABLE

  replace(abx_id, "_", "/") AS "略号",

  generic_ja AS "一般名",

  class_ja AS "分類",

  route AS "投与経路",

  choice(renal_adjust = "required", "🔴 必要",

    choice(renal_adjust = "no", "🟢 不要", "⚪ 不明")) AS "腎調整"

FROM "Drugs/Antibiotics"

WHERE type = "antibiotic"

SORT generic_ja ASC

```
